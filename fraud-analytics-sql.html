Fraud Analytics com SQL

Projeto educacional com dados sintéticos para demonstrar SQL aplicado à prevenção a fraudes financeiras.

5.008transações
R$ 37,4 mivolume financeiro
0,92%base priorizada

Objetivo

Explorar análise comportamental, investigação e priorização de alertas com SQL. O projeto usa PostgreSQL e Supabase, com CTEs e Window Functions. Alerta de risco não significa fraude confirmada.

Resultado principal

46 operações P1/P2 foram priorizadas, representando R$ 490.281,62 em operações e 0,92% da base analisada.

Pipeline

Schema→Dados sintéticos→Queries→Comportamento→Score→Views para BI

Stack

PostgreSQL · Supabase · SQL · CTEs · Window Functions · Git/GitHub.
