Automação de Extratos de Boletos

Da leitura de um CSV à geração de arquivos por cliente: um exercício de automação de rotina operacional com tratamento e proteção visual de dados.

100boletos
10clientes fictícios
10PNGs
1 ZIPfinal

1. Problema

Gerar extratos individualmente é repetitivo. O projeto automatiza seleção, agrupamento, cálculo, formatação e geração visual para cada cliente de uma base fictícia.

2. Leitura e preservação dos dados

df = pd.read_csv(
  "/content/boletos_ficticios.csv",
  sep=";", decimal=",",
  dtype={"cpf_cnpj": str}
)

O documento é lido como texto para preservar zeros à esquerda. A base contém 5 pessoas físicas e 5 empresas.

3. Pipeline de transformação

CSV→seleção por cliente→cópia→mascaramento→KPIs→formatação→PNG→ZIP

Privacidade visual

CPF/CNPJ e e-mail são parcialmente mascarados nas saídas geradas.

Escala

O processamento é repetido por cliente com groupby("cliente_id"), evitando geração manual.

4. Resultado

O fluxo produz extrato_C001.png até extrato_C010.png e compacta os extratos em um único arquivo para distribuição.

O projeto demonstra algo além de “usar Pandas”: traduz uma rotina operacional em um fluxo repetível, padronizado e auditável.

5. Limites reconhecidos

Os dados são fictícios; o mascaramento é parcial; não há emissão bancária nem processamento de pagamentos; e o layout não possui paginação automática. Esses limites são documentados para separar demonstração técnica de solução de produção.
