# Data Analyst Studio

**[FEITO COM AUXÍLIO DIRETO DE INTELIGÊNCIA ARTIFICIAL]**

Este projeto foi desenvolvido com auxílio direto de inteligência artificial, com decisões, validações, testes e refinamentos feitos ao longo do processo.

## Transparência de desenvolvimento

A assistência de IA foi usada para apoiar arquitetura, geração e revisão de código, implementação de recursos, identificação de bugs e refatoração. O projeto não é apresentado como código produzido sem assistência.

## Estado técnico atual

A versão Python refatorada corrige o parser numérico, usa SHA-256 para identificar arquivos, reduz recomputações no Streamlit, otimiza contagem de nulos e agregações geográficas, adiciona cache onde faz sentido, separa responsabilidades em módulos e inclui testes unitários.
