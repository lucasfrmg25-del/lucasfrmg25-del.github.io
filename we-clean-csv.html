06 / DATA QUALITY + PYTHON

WE CLEAN
.CSV

Uma ferramenta guiada para diagnosticar e tratar problemas comuns em arquivos CSV, mantendo o usuário no controle das decisões de limpeza.

O PROBLEMA

Arquivos tabulares chegam com nulos, duplicatas, colunas vazias e textos inconsistentes. Limpar sem rastreabilidade pode introduzir novos erros.

Versão: v1.0 funcional.

Stack: Python · Pandas.

ProblemaFluxoRecursosInsightsLimitesAplicação

PROBLEMA DE DADOS

01 / DATA QUALITY

Inconsistência

Nulos, duplicatas e textos mal padronizados comprometem análises posteriores.

Decisão de limpeza

Nem todo problema deve ser tratado automaticamente; o usuário precisa escolher a estratégia adequada.

FLUXO DA SOLUÇÃO

02 / PIPELINE
Importação→Diagnóstico→Colunas vazias→Duplicatas→Nulos→Textos→Relatório→Exportação

O QUE A V1.0 FAZ

03 / FEATURES

Diagnóstico

Linhas, colunas, tipos, nulos e duplicatas.

Nulos

Remoção, valor informado, média, mediana ou moda.

Textos

Remoção de espaços e padronização de caixa.

Relatório

Histórico das alterações e comparação antes/depois.

INSIGHTS

04 / LEITURA
INSIGHT 01

Limpeza é decisão

Uma ferramenta útil não deve apenas “corrigir”; ela precisa expor opções e consequências.

INSIGHT 02

Ordem das etapas importa

Nova checagem de duplicatas após padronizar textos evita perder duplicatas que só aparecem depois da normalização.

INSIGHT 03

Rastreabilidade aumenta confiança

Relatório antes/depois permite entender o que foi alterado antes de exportar o CSV final.

LIMITES E PRÓXIMOS PASSOS

05 / EVOLUÇÃO

Limites

A ferramenta cobre problemas comuns, mas não substitui regras específicas de domínio nem validações semânticas.

Próxima evolução

Adicionar perfis de qualidade, tipos esperados por coluna, regras customizadas e resumo visual mais detalhado.
